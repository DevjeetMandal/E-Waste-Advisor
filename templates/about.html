How this works

  1. Plan. An LLM agent decides which tools to call: a transparent keyword classifier, semantic search over India's e-waste documents, and (if you give a location) a recycler lookup. Safeguards force classification and at least one search even if the model skips them.
  2. Retrieve. Document pages are embedded locally; the closest passages become numbered evidence.
  3. Answer. A second call must return structured JSON. Citations are checked in code against what was actually retrieved, and the answer is marked "not covered" if retrieval similarity is below {{ min_score }} or no valid citation backs it.
  4. Photo input (optional). A pretrained YOLO model identifies common devices; the photo is processed in memory and not stored.
Responsible AI
  • Transparency: every rule-based claim links to a source page; the agent's steps are shown.
  • Fairness: guidance comes from official documents, not model assumptions; weak evidence is reported as weak.
  • Ethics: safety text and recycler names are never model-generated; users are steered to authorised channels.
  • Privacy: only the device description (and optional city/state) is used; photos are not stored.
Known limitations
  • Recycler data is the CPCB list as on 08-06-2023 and covers only {{ covered|join(', ') }} so far. Authorisations change.
  • "Hazard level", materials and risks are AI-assessed from general knowledge and can be wrong.
  • Photo detection covers only a few common devices and says nothing about condition.
  • Hindi and Odia output is machine-translated.
